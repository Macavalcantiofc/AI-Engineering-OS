# Cases

Cases transform conhecimento em evidência prática.

## Estrutura recomendada
Cada case deve registrar:
- contexto e problema
- hipótese
- solução/experimento
- arquitetura e decisões
- métricas
- resultado
- custo estimado vs. realizado
- aprendizados
- conhecimento promovido para `knowledge/`
- perguntas que permaneceram abertas

## Estados
`idea -> planned -> running -> completed -> validated`

Um case só deve ser considerado `validated` quando houver evidência suficiente para sustentar a conclusão.
