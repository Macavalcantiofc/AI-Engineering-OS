# Research

Espaço para pesquisas sobre tecnologias, modelos, plataformas e padrões emergentes.

## Princípios
1. Registrar a pergunta antes da conclusão.
2. Separar fatos, inferências e opinião.
3. Preferir fontes primárias e evidências reproduzíveis.
4. Registrar data, versão e contexto da tecnologia pesquisada.
5. Promover conclusões estáveis para `knowledge/` quando houver evidência suficiente.

## Workflow
`question -> research -> hypothesis -> experiment -> conclusion -> knowledge`
