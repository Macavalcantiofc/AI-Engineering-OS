# ADR-0001: AI Engineering OS Structure

- Status: accepted
- Date: 2026-09-10

## Context
The system needs to support continuous learning, research, practical application and AI-assisted software development without mixing transient notes with validated knowledge.

## Decision
Use a domain-oriented repository with explicit separation between knowledge, learning, research, cases, agents, cost engineering, decisions and templates.

## Consequences
Positive:
- easier navigation and retrieval
- versioned knowledge
- explicit distinction between hypothesis and evidence
- reusable agent contracts

Trade-off:
- requires periodic curation
- structure must evolve as the system is used
