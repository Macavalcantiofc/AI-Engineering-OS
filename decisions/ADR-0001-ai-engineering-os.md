# ADR-0001: AI Engineering OS Structure

- Status: accepted
- Date: 2026-09-10

## Context
The system needs to support continuous learning, research, practical application and knowledge review without mixing transient notes with validated knowledge or unrelated projects.

## Decision
Use a domain-oriented repository with explicit separation between knowledge, learning, research, cases, questions, agents, decisions, summit and templates.

The repository is exclusively the personal learning system. Independent projects, products and standalone engineering initiatives must remain outside the OS and may only be represented as learning material when explicitly relevant.

## Consequences
Positive:
- easier navigation and retrieval
- versioned knowledge
- explicit distinction between hypothesis and evidence
- reusable learning workflows
- clear boundary between the learning system and external projects

Trade-off:
- requires periodic curation
- structure must evolve as the system is used
