# AWS Summit 2026

## Context
Registro inicial dos aprendizados do AWS Summit 2026, realizado em setembro de 2026.

## Captura
Para cada talk/case registrar:
- problema
- serviço/tecnologia
- arquitetura
- decisão relevante
- benefício
- limitações
- aplicabilidade no contexto profissional
- perguntas geradas
- evidência/link

## Nota
Não transformar uma talk em verdade arquitetural automaticamente. Eventos são fontes de descoberta; validação deve ocorrer por documentação, experimento ou aplicação real.
