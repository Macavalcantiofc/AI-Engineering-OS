## Track 04 — SDD + Software Engineering

- decomposition
- contracts
- implementation plans
- tests and quality gates
- code review with AI

## Track 05 — Cloud
- AWS

- multicloud patterns

## Track 06 — Emerging Tech
- new model families

- agent protocols
- AI coding tools
- emerging developer platforms

## Progress rule
A topic moves from `planned` to `studying`, `experimented`, `validated` or `mastered` only when there is evidence recorded in the repository.
