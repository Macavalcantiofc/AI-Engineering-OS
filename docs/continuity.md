# Continuity

Contexto operacional curto para retomada. A fonte de verdade continua sendo o restante do repositório.

Estado atual: AI Engineering OS como sistema pessoal de aprendizagem contínua.

Tema atual: documento → chunking → embeddings → vector store → retrieval → RAG → contexto → LLM → tool calling → MCP → agent.

Foco: entender problema, abstração, arquitetura, trade-offs e momento correto de uso antes de implementar.

Fluxo de mudança: diagnóstico → proposta → branch → PR → revisão humana → merge.

Próximo passo: começar pelos fundamentos de particionamento, representação vetorial, indexação e recuperação antes de tratar RAG como arquitetura.

Este arquivo deve permanecer pequeno. Se virar memória infinita, falhamos no objetivo.
