# Vision

O AI Engineering OS é uma base viva para formar uma referência técnica em AI Engineering.

## Escopo
1. AI Engineering e LLM applications
2. Agentic AI e sistemas multi-agente
3. SDD e engenharia orientada por especificação
4. Software architecture e fullstack engineering
5. Cloud: AWS, Google Cloud, Azure e multicloud
6. Modelos, avaliação, observabilidade, segurança e custo
7. Tecnologias emergentes e cases reais

## Ciclo de evolução
`Learn -> Capture -> Validate -> Experiment -> Apply -> Measure -> Review -> Teach`

Cada conhecimento importante deve evoluir de hipótese para evidência e, quando aplicável, para padrão reutilizável.
