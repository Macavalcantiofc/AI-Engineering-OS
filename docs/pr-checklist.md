# Pull Request Checklist

Antes de fazer merge:

- [ ] A mudança pertence ao AI Engineering OS.
- [ ] O estado atual do GitHub foi considerado.
- [ ] Não existe duplicação desnecessária.
- [ ] A mudança está pequena e coerente.
- [ ] O PR explica o que mudou e por quê.
- [ ] O conteúdo distingue fato, hipótese e evidência quando necessário.
- [ ] O usuário revisou a alteração.
- [ ] O merge foi feito pelo usuário.
- [ ] O estado final foi verificado.
