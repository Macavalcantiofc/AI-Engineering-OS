# Questions Backlog

Perguntas devem ser tratadas como ativos de aprendizado, não como falhas.

## Prioridade
- P0: bloqueia decisão/execução atual
- P1: alto impacto profissional
- P2: importante para aprofundamento
- P3: curiosidade / exploração

## Workflow
`question -> research -> hypothesis -> experiment -> answer -> knowledge`
